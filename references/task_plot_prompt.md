# Task Plot Prompt

Create a clean scientific task-flow timeline diagram only.

Leave the top 25% of the image blank for a later fixed header, title, subtitle, and logo overlay. Do not draw any title, subtitle, logo, watermark, or branding.

Task: Paired-Associate Learning Task.

Draw three horizontal timeline rows:

1. Practice list
2. Scored list 1
3. Scored list 2

Use compact screen thumbnails connected by arrows. Use a white background, crisp dark labels, and restrained accent colors. Make row labels left aligned. Keep text legible and inside the timeline.

For each row, show a study segment followed by a test segment.

Practice list phases:

- Study fixation, 500 ms: fixation cross.
- Study pair, 1500 ms: cue word and associate word side by side; prompt `R=related  U=unrelated`.
- Study feedback, 800 ms: correct / incorrect / timeout.
- Study ITI, 400 ms: fixation cross.
- Test fixation, 500 ms: fixation cross.
- Test choice, 6000 ms: cue word at top and four word options in a 2x2 grid; prompt keys `1 2 3 4`.
- Test feedback, 800 ms: correct / incorrect / timeout.
- Test ITI, 400 ms: fixation cross.

Scored list phases:

- Study fixation, 500 ms.
- Study pair, 1500 ms, with `R=related` and `U=unrelated`.
- Study ITI, 400 ms.
- Test fixation, 500 ms.
- Test choice, 6000 ms, with keys `1 2 3 4`.
- Test ITI, 400 ms.
- Note: no corrective feedback.

Add small notes: 10 pairs per list; related/unrelated study judgments; 4-choice recognition test.
